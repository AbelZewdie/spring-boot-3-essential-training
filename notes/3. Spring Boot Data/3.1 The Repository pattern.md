Most Spring data is based on the **Repository pattern.**

# Spring JDBC
can be used to also create repository type actions or DAO actions.

# Repository Pattern

- Introduced as part of Domain-Driven Design
- Simple operations of an entity or business object without knowledge of other entities.
- Under the abstraction, the data access operations are hidden.

# Why use the Repository Pattern

- Databases have become the bottleneck.
- Prevent data access logic from leaking into your business logic.
- Provide a layer of abstraction to hide internals.
