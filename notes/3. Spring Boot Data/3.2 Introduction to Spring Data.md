# Data within Spring Boot

- Support for traditional RDBMS and NoSQL databases
- Based entirely on Spring Data project
- Starters leverage common defaults

	Certain databases auto-configure an embedded database.

# DataSources

- When properly configured, you will get a DataSource object.
- Can only have one database auto-configured.
- That DataSource can be injected if needed.
- Spring Boot will configure repositories for Spring Data.
