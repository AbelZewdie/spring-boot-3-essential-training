# Simple and Effective

- We don't always need Web or Rabbit
- We need to just do some work
- Think of admin tasks and batch operations

# CommandLineRunner Interface

- Provides access to application arguments
- Runs as a simple or complex set of tasks
- Can be used standalone or in an application
- Implement a single run method

# ApplicationRunner (AR) Interface
is the close cousin of CommandLineRunner

- Works the same as CommandLineRunner
- Single run method
- Access to application arguments

# Ordered Operations

- When leveraging multiple CLR or AR operations
- @Order annotation
