	Spring Boot Starter Security gives basic authentication on all of your endpoints.

	The majority of Spring Basic Security is based on property-based configuration.

# Form-Based Authentication

- Full support for form-based authentication
- Modify the `SecurityFilterChain`
- Use @EableWebSecurity
- Backed with datastore or in0memory (demo only)

# OAuth2

- Full support for OAuth2, server and client.
- Default implementation @EnableOAuth2Client
- @EnableAuthorizationServer to create and customize a simple authorization server.
- @EnableResourceServer to create a resource server.

# A note on Hashing

- Passwords should be hashed, not encrypted.
- SHA-1 should be considered owned
- Bcrypt is industry standard and should be used for form-based authentication.
