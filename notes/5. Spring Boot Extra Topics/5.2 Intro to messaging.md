	Why do we care so much about asynchronous messaging?

# Asynchronous Messaging

- Seldom is real-time processing a requirement
- Reduce system strain
- Improves efficiencies

## Async Message

| Producers | Consumers |
| --------- | --------- |
# Producers

- Spring provides template
- Default configurations
- For RabbitMQ, provide exchange and queue name
- Post message as string or object  

# Consumers

- Spring provides listener implementations
- Responds to messages on the queue and executes some logic
- Based on same paradigm as producer
