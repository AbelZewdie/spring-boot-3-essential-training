# Actuator

- Provides insights into your running applications.
- Provides configuration settings, usually through JMX.
- Allows you to monitor your running applications.

# Health Endpoint

- Up/down status of application
- up/down status of dependencies
- Application status only up if dependencies are up
- Great for liveness and readiness checks.

# Other Endpoints

- Beans
- Environment variables
- Info
- Metrics
- Many others

# Security and Customization

- Default is relatively locked down
- Ensure it's not publicly available
- Only configure what you need
- Customizable down to endpoint
- Can be extended with custom endpoints
