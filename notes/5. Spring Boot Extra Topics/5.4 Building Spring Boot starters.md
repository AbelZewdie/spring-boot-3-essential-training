	Why would I want to create my own starter?

# Starters

- Common code
- Common Configurations
- Improve ease of use

# Your Library

- Creating a starter is driven by a business or technical need
- Isolate the code by function and build a library for it
- Consider your dependencies wisely

# Build the Auto-configuration Module

- Can be included in the starter
- Should not be included in your library
- Create configuration and configuration properties as needed.
- Contains the spring.factories file in META-INF

# Build the Starter Module

- Usually an empty jar file
- Dependency on auto-configuration module and library
- Dependency on any other starter
