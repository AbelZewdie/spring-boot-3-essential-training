- Default servlet responds at / (the context root)
- Beans of type Servlet, Filter, or Listener will be scanned and loaded into Application Context.
- Additional `ServletContext` can be loaded through the `ServletContextInitializer` interface.

	The Easiest way to configure your embedded Tomcat is through the use of properties.

# Property Based

- `server.address`, `server.port`, `server.contextPath`
- Session-based configs (cookies, timeouts, etc.)
- Error page path

# Compression
is a common thing that people want to modify on a default spring boot application.

- `server.compression.enabled=true`
- Response must be 2048 bytes to compress by default.
- Response types will be compressed if they exceed the limit.
    1. text/html
    2. text/xml
    3. text/plain
    4. text/css

	The most common way to change the embedded servlet container is to migrate it from standard http to Transport Layer Security (TLS).
# TLS

- Native TLS support through properties.
- Most common embedded servlet change.
- Requires a Java Keystore that contains the certificate.
- Properties used to configure.
