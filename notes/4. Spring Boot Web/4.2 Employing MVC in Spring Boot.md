# Spring Model-View-Controller (MVC)

- Spring Boot provides default configurations for MVC.
- Simple paradigm based on Model-View-Controller pattern.
- Template engine starter provides view resolvers.
- Static file resolvers are built in.

# MVC Pattern

- Design pattern
- Model serves the data
- View formats the data with other text as appropriate.
- Controller responds to request, gathers model, and merges with view.
