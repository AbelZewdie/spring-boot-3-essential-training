# @EnableAutoConfiguration

- Allows for configuration classes to be scanned dynamically.
- Often based on jars loaded onto class path.
- Driven by spring.factories
- @AutoConfigureBefore and @AutoConfigureAfter

# Conditional Loading

- @ConditionalOnClass
- @ConditionalOnBean
- @ConditionalOnProperty
- @ConditionalOnMissingBean

# Properties

- Preconfigured default properties for AutoConfiguration classes.
- EnableConfigurationProperties specifies the default property set.
- Can always be overridden.

# Additional Conditionals

- Bean, missing bean, class, missing class based, property based
- Application type based
- Resource or file based
- Expression based
